Rider comfort check

Built at 1:26, the size of a mouse. The track banks along the riders' heartline so sideways g goes to zero, and curves ramp in gradually. G-forces don't change with scale, so the limits are the same as for a full-size coaster. A 1:26 model runs every motion √26 ≈ 5.1× faster, so roll rate is judged at its full-size equivalent.
